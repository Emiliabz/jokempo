# 🪨🧻✂️ Jogo Jokempô (Pedra, Papel e Tesoura) em Python

Este é um projeto simples e divertido que reproduz o clássico jogo **Jokempô** (Pedra, Papel e Tesoura). O usuário joga contra o computador em uma partida única, testando a tomada de decisões e a lógica estruturada do script.

## 🛠️ Tecnologias e Conceitos Praticados
* **Python**: Linguagem utilizada para construir toda a lógica do jogo.
* **Módulo `random`**: Utilização do método `randint` para fazer o computador escolher uma jogada aleatória entre as opções disponíveis.
* **Módulo `time`**: Utilização da função `sleep` para criar um efeito de suspense dramático na tela enquanto o clássico "JO-KEM-PO!" é ditado.
* **Estruturas Condicionais**: Aplicação de blocos `if`, `elif` e `else` para validar todas as regras do jogo e determinar quem é o vencedor.

## 🎮 Como Jogar?
Ao iniciar o script, o terminal exibirá um menu interativo com três opções:
* `[0] Pedra`
* `[1] Papel`
* `[2] Tesoura`

Basta digitar o número correspondente à sua jogada e pressionar **Enter**. O computador fará a escolha dele instantaneamente e o resultado (Vitória, Derrota ou Empate) aparecerá logo em seguida na tela!
